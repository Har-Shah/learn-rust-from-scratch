# Learning Log

One entry per session. The point of this file is honesty: it is the input to spaced review, so
recording "I needed the solution" is more useful than recording a clean-looking win.

**Confidence scale**
- **Explain** — I could teach this to someone else, including why it works
- **Recognize** — I follow it when reading, but could not produce it unaided
- **Fuzzy** — I have seen it and it did not stick
